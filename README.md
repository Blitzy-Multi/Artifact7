## Endpoints

| Method | Path            | Response       |
|--------|-----------------|----------------|
| GET    | `/`             | `Hello world`  |
| GET    | `/good-evening` | `Good evening` |

## Running

```bash
npm install
npm start
```

`npm start` runs `node index.js`. The server listens on `http://localhost:3000` by default (override with the `PORT` environment variable).
